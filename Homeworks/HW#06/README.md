## 4. Mathematical Formulation & Solutions

### 4.1 Section 1: Noiseless & Noisy Sparse Recovery via BP, MP, and LASSO (`Section1.m`)

#### Ground-Truth Structure of `hw6-part1.mat`

In `codes/hw6-part1.mat`, the dictionary $D \in \mathbb{R}^{5 \times 15}$ has $M = 5$ rows and $N = 15$ unit-norm columns ($`\|d_j\|_2 = 1`$ for $j = 1, \dots, 15$). The noiseless observation vector $x \in \mathbb{R}^{5 \times 1}$ ($`\Vert{}x\Vert{}_2 = 2.921572`$) is generated by a 2-sparse ground-truth vector $`s^* \in \mathbb{R}^{15 \times 1}`$ supported on atoms $2$ and $10$:

```math
x = D s^* = 1 \cdot d_2 - 2 \cdot d_{10},
\qquad
s_n^* = \begin{cases}
1, & n = 2, \\
-2, & n = 10, \\
0, & \text{otherwise}.
\end{cases}
```

The noisy observation vector is $`x_{\mathrm{noisy}} = x + v \in \mathbb{R}^{5 \times 1}`$ ($`\Vert{}x_{\mathrm{noisy}}\Vert{}_2 = 2.964852`$), where the additive noise vector $`v = x_{\mathrm{noisy}} - x`$ has Euclidean norm $`\|v\|_2 = 0.200000`$, corresponding to a relative noise level of:

```math
\frac{\|x - x_{\mathrm{noisy}}\|_2}{\|x\|_2} = \frac{0.200000}{2.921572} = 0.068456 \quad \left(\mathrm{SNR} \approx 23.29\ \mathrm{dB}\right).
```

#### Part الف (Part 1 in Code) — Basis Pursuit on Noiseless Data (`Section1.m` lines 7–17)

**Basis Pursuit (BP)** recovers the sparse representation by minimizing the convex $`\ell_1`$-norm subject to the exact linear equality constraint $x = D s$ (Page 1 of the report):

```math
\hat{s}_{\mathrm{BP}} = \arg\min_{s \in \mathbb{R}^N} \|s\|_1 = \sum_{n=1}^{N} |s_n|
\qquad \text{subject to} \qquad
x = D s.
```

Decomposing each unrestricted coefficient $`s_n \in \mathbb{R}`$ into non-negative positive and negative parts $`s_n = s_n^+ - s_n^-`$ with $`|s_n| = s_n^+ + s_n^-`$, where $`s_n^+ = \max(s_n, 0) \ge 0`$ and $`s_n^- = \max(-s_n, 0) \ge 0`$, and defining

```math
D_1 = \begin{bmatrix} D & -D \end{bmatrix} \in \mathbb{R}^{M \times 2N},
\qquad
y = \begin{bmatrix} s^+ \\ s^- \end{bmatrix} \in \mathbb{R}_+^{2N \times 1},
```

converts the problem into a standard $2N = 30$-variable **Linear Program (LP)**:

```math
\hat{y} = \arg\min_{y \in \mathbb{R}^{2N}} \sum_{i=1}^{2N} y_i
\qquad \text{subject to} \qquad
D_1 y = x, \quad y_i \ge 0 \quad (\forall i = 1, \dots, 2N).
```

Solving this LP via `y = linprog(ones(1, 2*N), [], [], D_1, x, zeros(1, 2*N))` and forming `s = y(1:N) - y(N+1:end)` recovers the exact 2-sparse ground-truth vector (Page 2 of the report):

```math
\hat{s}_{\mathrm{BP}} = \begin{bmatrix}
0 & 1 & 0 & 0 & 0 & 0 & 0 & 0 & 0 & -2 & 0 & 0 & 0 & 0 & 0
\end{bmatrix}^T,
```

with normalized error $\mathrm{err} = 7.6002 \times 10^{-17} \approx 0$.

#### Part ب (Part 2 in Code) — Matching Pursuit on Noiseless Data (`Section1.m` lines 19–37)

In `codes/Section1.m` (lines 20–36), **Matching Pursuit (MP)** is implemented without prior knowledge of $`N_0`$, running up to `max_N_0 = M = 5` iterations with stopping threshold `err_thr = 1e-2` ($10^{-2}$). At each iteration $i$:

1. Find the dictionary atom maximizing the signed inner product with the current residual: `[innerprodMax, ind] = max(x_r.' * D)`.
2. Insert the selected atom into the active dictionary matrix at its natural column position: `D_hat(:, ind) = D(:, ind)`.
3. Update the residual via single-atom projection subtraction: `x_r = x_r - innerprodMax * D(:, ind)`.
4. Re-estimate the full $15 \times 1$ coefficient vector on the active support via the Moore-Penrose pseudoinverse `S_hat = pinv(D_hat) * x` and evaluate the relative residual error $`\mathrm{err} = \|x - \hat{D}\hat{S}\|_2 / \|x\|_2`$.

Tracing the four iterations on `hw6-part1.mat`:

- **Iteration 1:** Selects atom $\mathrm{ind} = 2$ ($`\alpha_1 = 2.767792`$), giving $\mathrm{err} = 0.320159$.

- **Iteration 3:** Selects atom $\mathrm{ind} = 4$ ($`\alpha_3 = 0.499488`$), reducing $\mathrm{err}$ to $0.046006$.
- **Iteration 4:** After subtracting the projections along atoms $2, 12, 4$, the residual's inner product with atom $10$ becomes positive ($`\alpha_4 = 0.218280`$), so MP selects atom $\mathrm{ind} = 10$. Once `D_hat` contains columns $\{2, 4, 10, 12\}$—which is a $4$-column linearly independent sub-dictionary whose column span contains the true 2-sparse vector $`x = 1 \cdot d_2 - 2 \cdot d_{10}`$—the least-squares step `S_hat = pinv(D_hat) * x` assigns exact weights $+1$ to atom $2$, $-2$ to atom $10$, and numerical zeros ($\sim 10^{-16}\text{–}10^{-15}$) to the redundant atoms (Page 2 of the report):

**Answer:** **Yes** — on the noiseless data, MP (equipped with the least-squares back-projection `S_hat = pinv(D_hat) * x` after $`N_0 = 4`$ atom selections) recovers the exact ground-truth coefficients ($`s_2 = 1`$, $`s_{10} = -2`$, and machine-epsilon zeros elsewhere) with error $5.0851 \times 10^{-16}$.

#### Part د (Part 4 in Code) — LASSO / BPDN via Coordinate Descent (`Section1.m` lines 51–90)

In the presence of additive noise $`x_{\mathrm{noisy}} = D s + v`$, enforcing the hard equality $`D s = x_{\mathrm{noisy}}`$ is inappropriate. Instead, **LASSO (Least Absolute Shrinkage and Selection Operator)**—also known as **Basis Pursuit Denoising (BPDN)**—solves the unconstrained penalized optimization problem:

```math
\begin{aligned}
\hat{s}_{\mathrm{LASSO}} &= \arg\min_{s \in \mathbb{R}^N} \left\{ \left\|x_{\mathrm{noisy}} - D s\right\|_2^2 + \lambda \|s\|_1 \right\} \\
&= \arg\min_{s \in \mathbb{R}^N} \left\{ \left\|x_{\mathrm{noisy}} - \sum_{j=1}^{N} d_j s_j\right\|_2^2 + \lambda \sum_{j=1}^{N} |s_j| \right\},
\end{aligned}
```

where $\lambda > 0$ controls the trade-off between data fidelity ($`\Vert{}x_{\mathrm{noisy}} - D s\Vert{}_2^2`$) and sparsity ($`\Vert{}s\Vert{}_1`$).

**Coordinate Descent (Cyclic Soft-Thresholding) Derivation:** To minimize the objective with respect to a single coordinate $`s_i`$ while holding all other $N - 1$ coordinates $`\{s_j\}_{j \neq i}`$ fixed, define the partial residual excluding atom $i$:

```math
r_i = x_{\mathrm{noisy}} - \sum_{j \neq i} d_j s_j = x_{\mathrm{noisy}} - D_{(-i)} s_{(-i)},
```

and the scalar correlation between $`r_i`$ and the $i$-th unit-norm atom $`d_i`$ ($`\Vert{}d_i\Vert{}_2^2 = 1`$):

```math
\rho_i = r_i^T d_i.
```

Expanding $`\|r_i - d_i s_i\|_2^2 + \lambda |s_i| = \|r_i\|_2^2 - 2 \rho_i s_i + s_i^2 + \lambda |s_i|`$ and taking the subdifferential with respect to $`s_i`$ yields the closed-form **soft-thresholding operator** $`\mathrm{soft}_{\lambda/2}(\rho_i)`$ (Page 3 and Figure 1.1 on Page 4 of the report, implemented in `Section1.m` lines 66–79):

```math
\hat{s}_i = \mathrm{soft}_{\lambda / 2}(\rho_i) = \begin{cases}
\rho_i - \dfrac{\lambda}{2}, & \rho_i > \dfrac{\lambda}{2}, \\[8pt]
0, & -\dfrac{\lambda}{2} \le \rho_i \le \dfrac{\lambda}{2}, \\[8pt]
\rho_i + \dfrac{\lambda}{2}, & \rho_i < -\dfrac{\lambda}{2}.
\end{cases}
```

Sweeping cyclically over $i = 1, \dots, N$ (`N = 15`) for `iterNum = 100` outer iterations in `Section1.m`:

1. **Noiseless calibration ($\lambda = 1/8 = 0.125$, Page 4 of the report):** Applying LASSO to the noiseless vector $x$ with $\lambda = 0.125$ recovers the exact 2-sparse support $\{2, 10\}$ with zero false positives:

```math
\hat{s}_{\mathrm{LASSO, noiseless}}(\lambda = 0.125) = \begin{bmatrix}
0 & 0.9747 & 0 & 0 & 0 & 0 & 0 & 0 & 0 & -1.9598 & 0 & 0 & 0 & 0 & 0
\end{bmatrix}^T.
```

2. **Noisy LASSO recovery ($\lambda = 0.4$, Page 5 of the report):** Applying LASSO to `x_noisy` and sweeping $\lambda$ shows that **$\lambda \approx 0.4$** eliminates all three noise-induced false positives of Part ج and recovers the exact 2-sparse support $\{2, 10\}$:

```math
\hat{s}_{\mathrm{LASSO, noisy}}(\lambda = 0.4) = \begin{bmatrix}
0 & 0.8916 & 0 & 0 & 0 & 0 & 0 & 0 & 0 & -1.8488 & 0 & 0 & 0 & 0 & 0
\end{bmatrix}^T.
```

3. **Behavior across regimes of $\lambda$ (Page 5 of the report):**
   - **$0 < \lambda < 0.4$ (Under-regularized regime):** The sparsity penalty is too weak to suppress all noise correlations; the estimate retains extra non-zero coefficients ($`N_0 > 2`$), losing strict 2-sparsity.
   - **$\lambda \approx 0.4$ (Optimal regime):** Balances data fidelity and sparsity, recovering the exact 2-sparse support $\{2, 10\}$ with $`\hat{s}_2 \approx 0.8916`$ and $`\hat{s}_{10} \approx -1.8488`$.
   - **$0.4 < \lambda \le 2.1$ (Transition regime):** Both true atoms $2$ and $10$ remain active, but their magnitudes are increasingly shrunk toward zero by $\lambda/2$.
   - **$2.1 < \lambda < 4.2$ (Single-atom regime):** Because $`|\rho_2| \approx 1.05 < \lambda/2`$, atom $2$ is thresholded to zero and only the stronger atom $10$ ($`\vert{}s_{10}^*\vert{} = 2`$) survives ($`N_0 = 1`$).
   - **$\lambda \ge 4.2$ (Zero-vector / over-regularized regime):** Once $\lambda/2$ exceeds $`|\rho_{10}| \approx 2.08`$ ($\lambda \ge 4.2$), every coordinate falls inside the dead-zone $[-\lambda/2, \lambda/2]$, yielding the trivial all-zero vector $`\hat{s} = \mathbf{0}_{15 \times 1}`$ ($`N_0 = 0`$) and relative error $\mathrm{err} = 1$. *(See Section 5.4 for an implementation note explaining why `Section1.m` line 83 yields constant error `0.068456` for any non-zero $`\hat{s}_{\mathrm{noisy}}`$ on $0 < \lambda < 4.2$ and `1` at $\lambda = 4.2$.)*

### 4.2 Section 2: Low-Coherence Frame Design in 2D and 3D (`Section2.m`)

#### Definition and Role of Mutual Coherence

For a column-normalized dictionary (frame) $`D = \begin{bmatrix} d_1 & d_2 & \cdots & d_N \end{bmatrix} \in \mathbb{R}^{M \times N}`$ with $`\|d_i\|_2 = 1`$, the **mutual coherence** $\mu(D)$ is the maximum absolute inner product (cosine similarity) between any pair of distinct atoms:

```math
\mu(D) = \max_{1 \le i \neq j \le N} \left| d_i^T d_j \right| = \max_{1 \le i \neq j \le N} |\cos(\theta_{ij})|.
```

In sparse recovery, a smaller $\mu(D)$ guarantees better worst-case identifiability (e.g., exact recovery by BP and OMP is guaranteed whenever $`\|s\|_0 = N_0 < \frac{1}{2}\left(1 + \frac{1}{\mu(D)}\right)`$). Therefore, optimal frame design seeks to **pack $N$ lines through the origin in $\mathbb{R}^M$** so that the minimum angle between any two lines is maximized (the **Grassmannian line-packing problem**).

#### Part 1 — Analytical $2 \times N$ Frame in $\mathbb{R}^2$ (`Section2.m` lines 3–20)

Any unit-norm atom in $\mathbb{R}^2$ can be parameterized by its polar angle $`\varphi_i`$:

```math
d_i = \begin{bmatrix} \cos(\varphi_i) \\ \sin(\varphi_i) \end{bmatrix},
\qquad
\left| d_i^T d_j \right| = \left| \cos(\varphi_i - \varphi_j) \right|.
```

**Why spacing over $[0, 2\pi)$ fails for even $N$ (Page 6 of the report):** If one places $N$ vectors uniformly around the full circle $[0, 2\pi)$ at angles $`\tilde{\varphi}_k = 2\pi(k-1)/N`$, then for any **odd** $N$ the vectors and their negatives form $2N$ equally spaced rays, which is optimal. However, for any **even** $N$ ($N = 2m$), the atom at index $k + m$ has angle $`\tilde{\varphi}_{k+m} = \tilde{\varphi}_k + \pi`$, so $`d_{k+m} = -d_k`$. Because $`d_{k+m}`$ and $`d_k`$ are collinear (antipodal), their absolute inner product is $`|d_k^T d_{k+m}| = |-1| = 1`$, resulting in the worst possible coherence $\mu(D) = 1$.

**Unified solution on the upper half-plane $[0, \pi)$ (`Section2.m` lines 7–9):** Because $`|d_i^T d_j| = |\cos(\varphi_i - \varphi_j)|`$ is invariant to sign flips $`d_i \mapsto -d_i`$, each atom defines an undirected line through the origin and is uniquely represented by an angle $\varphi \in [0, \pi)$. Spacing all $N$ angles uniformly across $[0, \pi)$ works identically for **both even and odd $N$**:

```math
\varphi_k = \frac{(k - 1)\pi}{N}, \qquad k = 1, 2, \dots, N,
\qquad
D_{2 \times N} = \begin{bmatrix}
\cos(0) & \cos\left(\frac{\pi}{N}\right) & \cdots & \cos\left(\frac{(N-1)\pi}{N}\right) \\[4pt]
\sin(0) & \sin\left(\frac{\pi}{N}\right) & \cdots & \sin\left(\frac{(N-1)\pi}{N}\right)
\end{bmatrix}.
```

Under this construction, the minimum angular separation between any two lines is $`\Delta \varphi_{\min} = \pi / N`$, so the mutual coherence has the exact closed-form expression:

```math
\boxed{
\mu\left(D_{2 \times N}\right) = \cos\!\left(\frac{\pi}{N}\right), \qquad N \ge 2.
}
```

As shown in Figure 2.1 of the report (Page 7), $\mu(D)$ starts at $`\mu(D_{2\times 2}) = \cos(\pi/2) = 0`$ (two orthogonal axes), rises to $\cos(\pi/8) \approx 0.9239$ at $N = 8$ and $\cos(\pi/10) \approx 0.9511$ at $N = 10$, and approaches $1$ asymptotically as $N \to 35$ ($\cos(\pi/35) \approx 0.9960$). Because $M = 2$ offers very limited geometric degrees of freedom, $\mu(D)$ exceeds $0.9$ already by $N = 7$ ($\cos(\pi/7) \approx 0.9010$).

#### Part 2 — Iterative Stochastic $3 \times 10$ Frame Optimization in $\mathbb{R}^3$ (`Section2.m` lines 21–51)

In $\mathbb{R}^3$ ($M = 3$, $N = 10$), uniform 1D angular spacing is no longer applicable because points on the unit sphere $\mathbb{S}^2$ do not lie on a single circle. In `codes/Section2.m` (lines 22–46, Pages 7–8 of the report), an iterative **Stochastic Coordinate Replacement (Random Search on the Unit Sphere)** algorithm is implemented:

1. **Initialization (`lines 22–28`):** Draw a random Gaussian matrix `vecs = randn(3, 10)`, normalize each column to unit $`\ell_2`$-norm (`vecs = vecs ./ sqrt(sum(vecs.^2))`), and compute the initial mutual coherence:

```math
\mu(D) = \max_{i \neq j} \left| (D^T D)_{ij} \right| = \max \left| D^T D - \mathrm{diag}(\mathrm{diag}(D^T D)) \right|.
```

2. **Iterative greedy atom replacement (`lines 29–46`, `iterNum = 5e4`):** In each outer iteration `iter = 1:50000`, sweep over all $N = 10$ columns `col = 1:10`:
   - Form a candidate dictionary `test_vecs = vecs` in which column `col` is replaced by a freshly drawn isotropic unit vector on $\mathbb{S}^2$:

```math
\tilde{d}_{\mathrm{col}} = \frac{g}{\|g\|_2}, \qquad g \sim \mathcal{N}(\mathbf{0}, I_3).
```

   - Compute the candidate coherence $\mu(\tilde{D})$.
   - If $`\mu(\tilde{D}) < \mu_{\mathrm{best}}`$, accept the replacement (`final_vecs = test_vecs; final_mu_D = test_mu_D`).
   - Record `list_mu_D(iter) = mu_D` after scanning all $10$ columns.

As shown in Figure 2.2 of the report (Page 8), the monotonically non-increasing trajectory `list_mu_D` drops rapidly from $\approx 0.93$ in the first few thousand iterations and converges to:

```math
\mu\left(D_{3 \times 10}\right) = 0.6947.
```

**Comparison of 3D ($3 \times 10$) vs. 2D ($2 \times 10$):** For the same number of atoms $N = 10$, adding just one spatial dimension ($M = 3$ instead of $M = 2$) reduces the mutual coherence from $\cos(\pi/10) \approx 0.9511$ ($\approx 0.9$) down to **$0.6947$** ($\approx 0.69$). *(For reference, the theoretical Welch lower bound for $M = 3, N = 10$ is $\sqrt{\frac{N - M}{M(N - 1)}} = \sqrt{\frac{7}{27}} \approx 0.5092$, and the optimal 10-line Grassmannian packing in $\mathbb{R}^3$ has $`\mu^* = 1/\sqrt{5} \approx 0.4472`$, which random column-wise replacement approaches up to local minima.)*

### 4.3 Section 3: Dictionary Learning via MOD and K-SVD (`Section3.m` and `OMP.m`)

#### Part 1 — Mutual Coherence of the $10 \times 40$ Dictionary (`Section3.m` lines 6–11)

For the ground-truth dictionary $D \in \mathbb{R}^{10 \times 40}$ in `hw6-part3.mat` (where every column has unit $`\ell_2`$-norm, $`\|d_i\|_2 = 1`$), line 8 of `Section3.m` evaluates:

```matlab
[mu_D, ind] = max(abs((D.' * D) - eye(size(D, 2))), [], 'all');
```

which yields (Page 9 of the report):

```math
\mu(D) = \max_{1 \le i \neq j \le 40} \left| d_i^T d_j \right| = 0.868030 \approx 0.868,
```

attained between atoms $13$ and $38$ ($`\vert{}d_{13}^T d_{38}\vert{} = 0.868030`$).

#### Parts 2–5 — Alternating Minimization Framework: MOD vs. K-SVD (`Section3.m` lines 13–78)

Given the observation matrix $`X = \begin{bmatrix} x_1 & x_2 & \cdots & x_T \end{bmatrix} \in \mathbb{R}^{M \times T}`$ ($M = 10$, $T = 1500$) and the target dictionary size $M \times N$ ($10 \times 40$) with column-wise sparsity level $`N_0 = 2`$, dictionary learning seeks both a column-normalized dictionary $\hat{D} \in \mathbb{R}^{M \times N}$ and a sparse coefficient matrix $`\hat{S} = \begin{bmatrix} \hat{s}_1 & \cdots & \hat{s}_T \end{bmatrix} \in \mathbb{R}^{N \times T}`$ by solving:

```math
\left(\hat{D}, \hat{S}\right) = \arg\min_{D, S} \|X - D S\|_F^2
\qquad \text{subject to} \qquad
\begin{cases}
\|d_n\|_2 = 1, & \forall n = 1, \dots, N, \\
\|s_t\|_0 \le N_0, & \forall t = 1, \dots, T.
\end{cases}
```

Both **MOD** and **K-SVD** solve this non-convex joint optimization via **Alternating Minimization** over `iterNum = 50` iterations, starting from the **exact same random Gaussian initial dictionary** `D_hat_init = randn(M, N)` normalized column-wise (`Section3.m` lines 18, 20–21, 42–43). At the end of each iteration `iter`, the normalized **Representation Error** objective is recorded as:

```math
\mathrm{RErr}(\mathrm{iter}) = \frac{\left\|X - \hat{D}\hat{S}\right\|_F^2}{\|X\|_F^2}
= \frac{\mathrm{tr}\!\left((X - \hat{D}\hat{S})(X - \hat{D}\hat{S})^T\right)}{\mathrm{tr}\!\left(X X^T\right)}.
```

##### Stage 1 (Common to Both MOD and K-SVD) — Sparse Coding with Fixed $\hat{D}$ via `OMP.m`

Holding the current dictionary estimate $\hat{D}$ fixed, the problem decouples across the $T = 1500$ columns of $X$ into $T$ independent sparse recovery problems:

```math
\hat{s}_t = \arg\min_{s_t \in \mathbb{R}^N} \left\|x_t - \hat{D} s_t\right\|_2^2
\qquad \text{subject to} \qquad
\|s_t\|_0 \le N_0 = 2,
\qquad t = 1, 2, \dots, T.
```

In `codes/OMP.m`, each column $`x_t = X(:, t)`$ is sparsely coded in $`N_0 = 2`$ steps:

- **Step $i = 1$:** Select the atom with maximum absolute correlation `innerprod = x_r.' * D; [~, ind(1)] = max(abs(innerprod))`, and update the residual via `x_r = x_r - innerprod(ind(1)) * D(:, ind(1))`.
- **Step $i = 2$ ($i > 1$):** Select the second atom `ind(2)` maximizing `abs(x_r.' * D)`, form the $10 \times 2$ sub-dictionary `D_pr = D(:, ind(1:2))`, compute the joint least-squares coefficients `s_hat(ind(1:2)) = pinv(D_pr) * x`, and update `x_r = x_r - D * s_hat`.

##### Stage 2A — Dictionary Update in MOD (Method of Optimal Directions, `Section3.m` lines 31–32)

In **MOD**, holding the entire sparse coefficient matrix $\hat{S} \in \mathbb{R}^{N \times T}$ fixed, the unconstrained least-squares dictionary update minimizing $`\|X - D \hat{S}\|_F^2`$ is computed in closed form for all $N$ atoms simultaneously via the right Moore-Penrose pseudoinverse of $\hat{S}$, followed by column-wise $`\ell_2`$-normalization:

```math
\tilde{D}_{\mathrm{MOD}} = X \hat{S}^\dagger = X \hat{S}^T \left(\hat{S} \hat{S}^T\right)^{-1},
\qquad
\hat{d}_n = \frac{\tilde{d}_n}{\|\tilde{d}_n\|_2}, \quad n = 1, \dots, N.
```

##### Stage 2B — Dictionary and Coefficient Update in K-SVD (`Section3.m` lines 52–64)

Unlike MOD (which updates all columns of $\hat{D}$ while keeping the non-zero values of $\hat{S}$ frozen), **K-SVD** updates the dictionary **atom by atom** ($i = 1, 2, \dots, N$), simultaneously updating the $i$-th atom $`\hat{d}_i`$ **and** the $i$-th row of active coefficients $\hat{S}(i, \mathrm{ind})$ while preserving the support pattern:

1. **Compute the partial representation error matrix $`X_r^{(i)}`$ excluding atom $i$ (`lines 53–54`):** Let $n = \{1, \dots, N\} \setminus \{i\}$ be the indices of all other $N - 1 = 39$ atoms:

```math
X_r^{(i)} = X - \sum_{j \neq i} \hat{d}_j \hat{S}(j, :) = X - \hat{D}(:, n)\, \hat{S}(n, :) \in \mathbb{R}^{M \times T}.
```

2. **Restrict $`X_r^{(i)}`$ to the columns that actively use atom $i$ (`lines 55–56`):** Identify the subset of observation indices $\mathrm{ind} = \{t \in \{1, \dots, T\} : \hat{S}(i, t) \neq 0\}$ where atom $i$ was selected during the OMP step, and extract the submatrix:

```math
M_{X_r}^{(i)} = X_r^{(i)}(:, \mathrm{ind}) \in \mathbb{R}^{M \times |\mathrm{ind}|}.
```

   Restricting to $\mathrm{ind}$ ensures that the rank-1 update of $`\hat{d}_i \hat{S}(i, :)`$ only modifies entries of $\hat{S}(i, :)$ that are already non-zero, strictly preserving the sparsity constraint $`\|\hat{s}_t\|_0 \le N_0`$.
3. **Rank-1 approximation via SVD (`lines 57–63`):** Compute the Singular Value Decomposition `[U, G, V] = svd(m_Xr)`:

```math
M_{X_r}^{(i)} = U G V^T,
```

   locate the largest singular value $`\sigma_{\max} = G(\mathrm{index(end)}, \mathrm{index(end)})`$ with corresponding left and right singular vectors $`u_{\max} = U(:, \mathrm{index(end)})`$ and $`v_{\max} = V(:, \mathrm{index(end)})`$, and update atom $i$ and its active coefficient row simultaneously:

```math
\hat{D}(:, i) = u_{\max},
\qquad
\hat{S}(i, \mathrm{ind}) = \sigma_{\max} v_{\max}^T.
```

##### Part 5 — Successful Recovery Rate (SRR) Computation (`Section3.m` lines 36–38 and 68–70)

After $50$ iterations, the cross-correlation matrix between the learned dictionary $\hat{D}$ and the ground-truth dictionary $D$ is formed as:

```math
C = \hat{D}^T D \in \mathbb{R}^{N \times N},
\qquad
C_{ij} = \hat{d}_i^T d_j.
```

In `Section3.m` (lines 37 and 69), the **Successful Recovery Rate (SRR)** is computed by counting how many entries of $|C|$ exceed the $0.98$ threshold, normalized by $N = 40$:

```matlab
corr_MOD  = D_hat_MOD.' * D;
SRR_MOD   = sum(abs(corr_MOD) > 0.98, 'all') / N;

corr_KSVD = D_hat_KSVD.' * D;
SRR_KSVD  = sum(abs(corr_KSVD) > 0.98, 'all') / N;
```

*(See Section 5.4 for a note comparing `sum(abs(corr) > 0.98, 'all') / N` with greedy without-replacement column matching; because distinct learned atoms in a well-converged dictionary rarely exceed $0.98$ correlation with the same true atom, both expressions yield virtually identical recovery rates.)*

#### Part 6 — Resolving Permutation and Scale/Sign Ambiguities for Source Error $E$ (`Section3.m` lines 80–93)

Because dictionary learning recovers the columns of $D$ up to an arbitrary **column permutation** and **$\pm 1$ sign flip** (the unit-norm constraint $`\|d_n\|_2 = 1`$ already fixes the magnitude scale of each column of $\hat{D}$ and therefore of each row of $\hat{S}$), the rows of $\hat{S}$ must be aligned with the rows of $S$ before computing the relative Frobenius error $E$:

1. **Permutation alignment (`lines 82–85`):** For each column $j \in \{1, \dots, N\}$ of the $40 \times 40$ correlation matrix $C = \hat{D}^T D$ (corresponding to the $j$-th true atom $`d_j`$), find the row index $`\mathrm{ind}(j) = \arg\max_{1 \le i \le N} |C_{ij}|`$ of the best-matching learned atom (`[~, ind_MOD] = max(abs(corr_MOD))`), and reorder the rows of $\hat{S}$ accordingly:

```math
\hat{S}_{\mathrm{sort}} = \hat{S}(\mathrm{ind}, :) \in \mathbb{R}^{40 \times 1500}.
```

2. **Sign ambiguity removal (`lines 86–87`):** Taking the element-wise absolute value of both $`\hat{S}_{\mathrm{sort}}`$ and $S$ removes any relative $\pm 1$ sign flip between each learned atom $`\hat{d}_{\mathrm{ind}(j)}`$ and true atom $`d_j`$:

```math
\Delta_{\mathrm{MOD}} = \left|\hat{S}_{\mathrm{sort, MOD}}\right| - |S|,
\qquad
\Delta_{\mathrm{KSVD}} = \left|\hat{S}_{\mathrm{sort, KSVD}}\right| - |S|.
```

3. **Relative squared Frobenius error (`lines 88–89`):** Using $`\|A\|_F^2 = \mathrm{tr}(A^T A)`$, compute:

```math
E = \frac{\|\Delta\|_F^2}{\|S\|_F^2} = \frac{\mathrm{tr}\!\left(\Delta^T \Delta\right)}{\mathrm{tr}\!\left(S^T S\right)}.
```

In the Persian report (Pages 11–12), this yields **$E_{\mathrm{MOD}} = 0.47698$** and **$E_{\mathrm{KSVD}} = 0.32125$**, confirming that K-SVD achieves a lower source estimation error than MOD.

- **Single-Step Orthogonalization in `OMP.m` (lines 8–14):**
  - In `codes/OMP.m`, when $i = 1$ (the `else` branch on line 13), the code updates the residual `x_r = x_r - innerprod(ind(1)) * D(:, ind(1))` without writing `s_hat(ind(1)) = innerprod(ind(1))` into `s_hat`. Because `Section3.m` calls `OMP` with $`N_0 = 2 > 1`$, the second iteration ($i = 2$) always enters the `if i > 1` branch (`lines 8–11`), which jointly computes both non-zero coefficients `s_hat(ind(1:2)) = pinv(D_pr) * x`. (If `OMP.m` were called with $`N_0 = 1`$, adding `s_hat(ind(1)) = innerprod(ind(1));` inside the `else` branch would be required.)
- **Ascending Singular Value Sort and Empty-Support Guard in `Section3.m` (K-SVD, lines 55–63):**
  - On line 60 of `Section3.m`, `[~, index] = sort(diag(G(1:L, 1:L)))` sorts the singular values in ascending order, so `index(end)` selects the **maximum singular value** $`\sigma_1 = G(1,1)`$ and its dominant singular vectors `U(:, 1)` and `V(:, 1)`. Note that if a random dictionary atom $i$ happens not to be selected by any of the $T = 1500$ signals during an iteration (`all(ind == 0)`, so `m_Xr` is $10 \times 0$ and `L = 0`), `index(end)` would index an empty array; in practice, with $T = 1500$ columns and $`N_0 = 2`$ ($3000$ atom selections across $N = 40$ atoms, averaging $75$ uses per atom), every atom is active (`nnz(ind) > 0`) in typical runs.
- **Total Threshold Count vs. Greedy Without-Replacement Atom Matching in `Section3.m` (Part 5, lines 37 & 69):**
  - The assignment sheet (Section 3, Part 5) describes a sequential without-replacement matching procedure (for each column of $\hat{D}$, find its maximum correlation with the remaining columns of $D$, and if $> 0.98$, count it as recovered and remove that column of $D$). In `Section3.m` (lines 37 and 69), this is approximated in one line as `SRR = sum(abs(corr) > 0.98, 'all') / N`. Because the ground-truth dictionary has $\mu(D) = 0.868 < 0.98$, a single learned atom $`\hat{d}_i`$ cannot simultaneously have $`|d_j^T \hat{d}_i| > 0.98`$ with two distinct true atoms $`d_j \neq d_k`$, and distinct learned atoms rarely collapse onto the same true atom above $0.98$. Similarly, in Part 6 (`lines 82–83`), `[~, ind_MOD] = max(abs(corr_MOD))` takes the column-wise maximum over rows of `corr_MOD` ($\hat{D}^T D$), mapping each true atom $j \in \{1, \dots, 40\}$ to its closest learned atom $\mathrm{ind}(j)$.
